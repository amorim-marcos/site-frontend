# Berneck Frontend

## Dependências

Projeto construído utilizando node 14

## Initial Setup

Instalação de dependências:

```bash
$ npm install
```

## Inciando a aplicação

### Development

Para iniciar a aplicação em ambiente de desenvolvimento:

```bash
$ npm run dev
```

### Build

Para iniciar a aplicação em ambiente de produção:

```bash
$ npm run build
$ npm run start
```
